Erro de Domínio Não Autorizado!

O Firebase bloqueou o login porque este site ainda não foi cadastrado como domínio confiável.

Como resolver:

  1. Vá no painel do seu Firebase Console.
  2. Acesse Authentication ➔ Settings ➔ Authorized domains.
  3. Adicione o domínio atual de hospedagem nas configurações.

Apenas o e-mail de administrador cadastrado possui acesso.

Dica de Configuração Avançada (Realtime Database):

Para habilitar a leitura automática em tempo real dos usuários que se cadastram no seu app, substitua a sua regra do nó "usuarios" para liberar apenas seu e-mail como leitor total:

"usuarios": {
  ".read": "auth != null && auth.token.email === 'geilsomcarlos93@gmail.com'",
  "$uid": {
    ".read": "$uid === auth.uid",
    ".write": "$uid === auth.uid"
  }
}

Enquanto as regras de segurança não forem alteradas, você pode adicionar e dar apelidos para usuários colando o UID deles acima!
