👥 Controle de Usuários (Apelidos & Acesso)

Bloqueie usuários de acessar o app e dê apelidos legíveis a cada UID.

Como Ativar Leitura Automática de Usuários:

Para o painel listar os usuários cadastrados automaticamente, vá na aba Regras (Rules) do seu Realtime Database e altere a regra de "usuarios" para permitir que apenas seu e-mail leia a lista completa:

"usuarios": {
  ".read": "auth != null && auth.token.email === 'geilsomcarlos93@gmail.com'",
  "$uid": {
    ".read": "$uid === auth.uid",
    ".write": "$uid === auth.uid"
  }
}

Enquanto não alterar, você pode simplesmente adicionar os UIDs manualmente usando o campo acima!
