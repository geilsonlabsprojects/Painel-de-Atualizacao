Erro de Domínio Não Autorizado!

O Firebase bloqueou o login porque este domínio não está registado como fidedigno.

Como resolver:

  1. Aceda ao seu painel do Firebase Console.
  2. Vá a Authentication ➔ Settings ➔ Authorized domains.
  3. Adicione o domínio desta página para autorizar a autenticação.

Apenas o correio eletrónico administrador tem permissão.

Dica de Configuração Avançada (Realtime Database):

Para habilitar a leitura automática em tempo real dos utilizadores que se registam na sua app, substitua a regra do nó "usuarios" no Firebase Console para permitir que apenas o seu e-mail leia a lista geral:

"usuarios": {
  ".read": "auth != null && auth.token.email === 'geilsomcarlos93@gmail.com'",
  "$uid": {
    ".read": "$uid === auth.uid",
    ".write": "$uid === auth.uid"
  }
}

Enquanto as regras não forem atualizadas, pode monitorizar utilizadores inserindo e salvando o UID deles manualmente no campo acima.
